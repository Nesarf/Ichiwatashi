# Where this came from: volcano hand-authored its table before the family rule existed, so
# its glyphs are the starting point -- but not copied blindly. Two entries in it are
# defective, and a shared asset must not inherit them:
#
#   Q   was 16 digits; the renderer reads only the first 14, so its last pair was
#       unreachable. Truncated here to the 14 that were ever drawn.
#   /   had row 5 = 0x20 = 32, and five columns are bits 4..0, so bit 5 is a column that
#       does not exist and the renderer dropped that row silently. Repaired to the
#       leftmost column, which continues the diagonal row 4 leaves off.
#
# Both repairs are recorded in volcano's own tests as pinned defects, so this file and that
# table intentionally differ in exactly two places.
