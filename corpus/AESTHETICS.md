## 一、轮郭線：`セルアウト` —— 而它解释了一个我已经量到的数

**来源**：[ドット絵の輪郭線とアンチエイリアス — セルアウト解説 | Pixnote](https://pixnote.net/learn/outlines/)

日式像素画把描边分四类（原文用同一精灵可切换对比）：

| 処理 | 原文说明 |
|---|---|
| **縁なし** | 明るく軽い印象。背景と分離しにくい |
| **ハード縁取り** | 全周を暗色で囲う。視認性は最高だが重く、漫画/ゲームUI調 |
| **セルアウト**（選択的輪郭線） | **背景に接する側だけ暗線、光側は内部の明色に。軽さと視認性を両立。プロの定番** |
| **アンチエイリアス** | 段差の角に中間色を 1px。なめらかに見えるが、やりすぎるとボケる |

### セルアウト的修法（原文四步）

1. 先全周ハードな暗色で囲い、シルエットを確定
2. **光が当たる側（多くは上・左）の輪郭線を、ボディの明るい色に置き換える**
3. **背景と接する側（下・右）の暗線は残す** —— シルエットを守るため
4. 必要なら暗線とボディの間に中間色を 1px 挟んで馴染ませる

> **輪郭線の色は「真っ黒」より「ボディの最暗色をさらに暗くした色」が自然です。**
> **純黒(#000)はゲームUI以外では浮きやすく、色味のある暗色にすると一気にプロっぽくなる。**

### ★ 而它解释了我实测的一个数

**「ボディの最暗色をさらに暗く」= 描边色是内色的函数。** 而我量到的正是这件事：

| | `outline_predictability` |
|---|---|
| **TH155 真作（160 张）** | **0.996** |
| 我合成の「随内色变化」 | 0.886 |
| 我合成の「随机 6 色池」 | 0.266 |

**所以 0.996 不是巧合，是「セルアウト」这条技法的必然结果** —— 而**随机杂色**在真作里**不存在**（分离度 0.266 那一档）。

### ★ 而它指出了我该测的**第二个量**

**セルアウト是按光向不对称的**：光侧（上・左）用明色，背侧（下・右）留暗线。
**而我现在的 `outline_variation` / `predictability` 都是对称的** —— 它不区分「上侧描边」与「下侧描边」。

### ✗ 而这个预测我测了，**它失败了**

按「上/下各半，比较描边像素的平均明度」量 160 张真 TH155 精灵：

```
positive (上侧更亮): 47 / 160 = 29%
pooled median = 0.000     pooled mean = 0.103
doremy +1.234 · futo -0.753 · hijiri +0.015 · reimu -0.083
```

**中位数是 0，而只有 29% 为正** —— 与セルアウト 的预期相反。

**两种解释，而我现在分不出是哪种**（这条要留着，别当结论）：

1. **TH155 的精灵确实不做セルアウト** —— 它们本来就是平色描边（我量到 `variation` 中位数 0.003、
   `outline_colours` 中位数 2），所以「光侧换明色」这件事在它们身上根本没发生
2. **我的量法太粗** —— 「上/下半」不是「光侧/背侧」；而且明度差被大量**同一个描边色**稀释到 0

**要分开这两者**，该做的是：**先按描边色分组**，再看**每一组内部**是否有光向不对称。
如果所有描边像素本来就是同一个色，那任何分带都必然读出 0 —— **那第一版测的就不是不对称，是「描边色有几个」。**

**所以这一条现在不是判据，是一个待做的实验。**

### AA 的可用规则（原文 DO / DON'T）

| DO | DON'T |
|---|---|
| 長い斜線・曲線にだけ控えめに | 全エッジにかけない（ボケる） |
| 中間色は 1px、最大 2px | 小さいスプライト（16px 以下）で多用しない |
| 背景色が決まってから最後に | 外側にはみ出す AA でシルエットを崩さない |
| シルエットの外形を守る範囲で | 透過背景前提の AA を不透明背景で使わない |

> **「AA は拡大して見せるものではなく実寸でなじませるもの」** ——
> 这解释了我在 うごイラ 上遇到的误报：那些是**渲染帧、满画布、不透明**，
> 于是 `bbox_fill` 读 1.000、`outline_variation` 读 0.000，40/40 被误报。

## 二、配色与调色板设计：四条原则，四条可测

**来源**：[ドット絵の配色とパレット設計｜色数を絞るほど、絵は良くなる | Code and DESIGN](https://code-and-design.jp/blog/pixel-art-color-palette.html)

| 原則 | 原文要点 | 对应的可测量 |
|---|---|---|
| **① 明度差がすべての土台** | 「色が濁る原因の8割は明度差不足」。**グレースケールにして形が判別できるか** | 明度ヒストグラム / グレースケール下の輪郭可視性 |
| **② ヒューシフト** | 影は**明度を下げるだけでなく色相もずらす**。ハイライトは**黄色寄り**、影は**青・紫寄り**。**影は彩度を上げる**（下げると灰色に近づいて絵が死ぬ） | 色相の明度依存（hue-vs-value 回帰の傾き） |
| **③ カラーランプ** | 1色につき 3–5 色の並び。**明度間隔は均等にしない** —— 目は明部に鈍く暗部に敏感なので**暗側は狭く、明側は広く** | ramp の明度間隔分布 |
| **④ 絵全体で色を共有** | **ランプの端を共有する**（髪の最暗色を服の影にも、肌のハイライトを金具にも、**最暗色を全体の輪郭線に統一**） | 配色の跨部件再利用率 |

**① 的具体指針（原文）**：

- ベース色と影色の明度は**はっきり離す** —— 少し暗くした程度では効かない
- **隣り合う色は明度で区別できるように** —— 色相だけ違う同じ明るさの2色は境界が溶ける
- ハイライトは**狭く、強く** —— 広く薄く置くとただ白っぽくなる
- **まず明度、次に色相、彩度は最後**

**⑤ 背景とキャラクターを分離**：背景は彩度を落とし明度を中間に、キャラは彩度を上げ明度幅を広く。

### ★ 而 ④ 正好解释了我量到的另一个数

> 「最も暗い色を全体の輪郭線に統一」

**TH155 真作的 `outline_predictability = 0.996`** —— 描边色几乎完全由内色决定。
**而 ④ 说的「最暗色统一做轮廓」会让 `outline_colours` 变小**（我量到真作中位数是 **2**）。
**两个数是同一条技法的两面。**
