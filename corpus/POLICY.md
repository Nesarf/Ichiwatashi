# Ichiwatashi 语料池的准入规则

> **这份文件的作用是「先定规则、再抓样本」。** 反过来做会抓回一堆混合来源，
> 然后每一条指标的分歧都变成「这是画风差异还是来源差异」——**而那个问题无法从数据回答**。

---

## 一、池子的一句话定义

**日式萌系向 ACG 的像素画。** 不是「像素画」——后者会把西方像素游戏、8-bit 复古风、
工业图标、地图瓦片、程序化生成的纹理全部吸进来，而**它们的描边约定、配色结构、形体语言
与目标是不同的**，混在一起之后参照表就没有意义了。

## 二、为什么这条是硬要求（不是偏好）

**已经实测到的代价。** 语料池的前身是 **TH123 的 120 张精灵**，而那一组参照值被拿去
判 **TH155** 的精灵，结论是：

| | TH123 参照 | TH155 实测 |
|---|---|---|
| `outline_variation` 中位数 | **0.726** | **0.003** |

**而两代都是正确作品。** 于是 TH155 那一代**每一张**都被报警（`outline_variation` 远在 p05 之下）。
**这不是判据算错，是参照被来源锁死了** —— 而当时没人知道 120 张只来自一款游戏。

**所以来源必须是一等字段，不是备注。**

## 三、准入三门

### 门 1：排除（一票否决）

任一命中即 **拒收**，并记录拒收理由：

| 排除项 | 为什么 |
|---|---|
| **非 ACG**：西方像素游戏、8-bit 复古、工业/地图/图标素材 | 描边与配色约定不同 |
| **非萌系向**：写实比例、硬核军事/恐怖题材的像素 | 形体语言不同 |
| **程序化生成**：噪声纹理、瓦片自动生成、AI 生成 | **不是人手画的**，而判据要测的正是手绘约定 |
| **已被重编码的**：JPEG 重建、缩放过的、调色板被量化过的 | **量化会把 `palette_size` 钉死**（已实测：第二语料的 16 就是我的量化值，那一行不是艺术证据） |
| **来源不明**：找不到出处的「网络像素图合集」 | 无法记录来源世代 |

### 门 2：采纳（至少两项正面证据）

| 证据 | 例子 |
|---|---|
| **出处是 ACG 作品** | 某游戏/动画/同人本的拆包或扫描 |
| **作者是 ACG 画师** | 有署名的 pixiv/Twitter 作品 |
| **元数据是 ACG 的** | 原始文件名/目录结构属于某作品（`data/character/<char>/`、`<作品>_<角色>`） |
| **风格可判** | 萌系比例、大眼、简化五官、日式配色 |
| **无损** | 8bpp 索引色 / 无损 PNG，**未经重编码** |

**只有一项正面证据 → 进「待议」，不进参照表。**

### 门 3：隔离（合成与处理过的另立一栏）

**任何我造的、改过的、放大过的样本，一律 `derived: true` + `derived_from` 指向源 sha256。**

理由是一条已经踩过的教训：**`pixel_scale` 的反例是我合成的放大图**。
它必须能被拿来验证判据，**但绝不能进参照表** ——
否则「真手绘的分布」里就混进了我自己的合成物，而那是循环论证。

## 四、来源世代（`generation`）是一等字段

**已实测：`TH105 ≡ TH123`**（四个角色、六个指标、12 个对照到小数点后三位一致），
**所以世代只需两档，不是三档**：

| `generation` | 含义 |
|---|---|
| `th105/th123` | 2008–2010 商业格斗精灵 |
| `th155` | 2017 商业格斗精灵 |
| `ugoira` | 2010s うごイラ（**渲染帧，不是精灵** —— 判据会识别并明说） |
| `other_acg` | 其他 ACG 来源 |
| `synthetic` | **我造的，永进参照表** |

**参照表的每一行必须标注它来自哪个世代。** 没有这一栏，TH123 那种误报会再发生一次。

## 五、记录什么，不记录什么

**照「语料事实可提交、样本本体不进仓库」的形态**（同族工具已有先例）：

```
corpus/
  POLICY.md          ← 这份
  README.md          ← schema 说明
  manifest.jsonl     ← 一行一条事实，可提交、可 diff
  sources.jsonl      ← 每个来源一条：URL、许可态度、抓取方式、时间
```

**样本本体存在仓库外**（当前：`E:\DaShaoHuo\downloads\ichiwatashi-corpus\`），
`manifest.jsonl` 里只留 `sha256` 与 `path_hint`。**sha256 是身份，路径只是提示。**

**为什么不存样本**：一半原因是体积与许可，**另一半更重要** ——
**测量才是贵的那部分，而样本是可复现的**。（同族的 Torikago 丢过一次 248 条测量记录，
清单与记录都写在仓库里正是为了这个。）

## 六、指标可用性随来源而变（已实测，必须一起记）

**同一批样本，不同指标的可信度不同**：

| 指标 | 可用性 | 依据 |
|---|---|---|
| `bbox_fill` · `pixel_scale` | **任何来源都可用** | 纯几何量，对调色板 0% 变化 |
| `outline_variation` + `predictability` | **必须按世代分档读** | TH123 0.726 vs TH155 0.003 |
| `palette_size` | **只在无损来源上可用，且必须记录用了哪个调色板** | 92.5% 的精灵会随调色板变，median spread 27 |
| `clusters` · `dither_pixels` · `isolated_rate` | 可用，但需固定调色板 | 常动，幅度小（相对值 0.01–0.03） |

**这一栏随 `generation` 一起写进 `sources.jsonl`。**
